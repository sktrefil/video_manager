# 범용 움직임 보정 1차 진행 기록

시작: 2026-10-12 · 범위: M0~M3 및 UI/배치 연결

## 상태

- M0: 기존 엔진 스냅샷·입력 해시·고정 합격 기준 보존 완료. 조정용 13개와 독립 검증용 13개 합성 영상을 분리했다. [기준선](M0_BASELINE.md), [독립 재현](M0_INDEPENDENT_VERIFICATION.md).
- M1~M3: `motion-components-v2.4` 구현 및 합성 기술 독립 검증 통과. 종횡비 유지·카메라/지역 움직임 분리·판단 보류·전체 출력 프레임 기준 제약 최적화·구형 보고서 호환을 연결했다.
- 검증 중 발견한 의도된 정지 오보정 및 국소 점수와 전체 출력 점수 차이를 수정했다. 합격 임계값은 변경하지 않았다. 과거 실패 기록도 [독립 검증 보고서](M1_M3_INDEPENDENT_VERIFICATION.md)에 남긴다.
- 반복/정지는 의도를 구분할 근거가 없어 진단만 표시한다. 추적 문맥 누락·낮은 신뢰도·보호 구간·효과 부족은 보정을 적용하지 않는다. 기본 자동 선택은 없다.
- 실제 자료의 일반화: 사용자가 다른 범주 영상이 없다고 확인했다. 인물·풍경·제품·빠른 동작의 실제 정상/문제 영상 검증은 대기이며 합성 검사로 대체 완료하지 않는다.
- 실행 환경 제약: 이 도구 세션의 QProcess 스모크에서 waitForStarted=False, 오류 `pipe: 작업을 완료했습니다.`가 발생한다. 외부 작업자의 실제 사용자 UI에서도 같은 문제라고 단정하지 않는다. 직접 엔진 실행과 UI 상태 검사 결과를 구분하고 GUI 자식 프로세스 종단 검증은 별도로 표시한다.

구현 완료·독립 검증 완료·실제 시각 품질 확인은 별도 판정한다. 필수 검증 실패는 수정 후 재검증하며 임계값을 낮춰 통과시키지 않는다.

## 최종 기술 검증

- 독립 작업자: 단위·시간 매핑·통합 검사 23개 통과, 독립 평가 13개 × 목표 길이 4개 = 52개 매핑 검사. 실행 중 제품 해시 불변.
- 정상 사례 오보정 0건, 의심 구간 탐지 2/2, 컷 경계·보호 구간·끝점·단조성·최대 배속 제약 통과. 탐지는 결함이나 의도를 확정하는 지표가 아니다.
- 속도 급변 사례의 3초 출력에서 원본 프레임 선택 9개 변경, 독립 정답 기준 전체 가속 변동 13.341% 감소, 이동 범위 유지 및 반복 증가 없음. 같은 사례의 2.5초 출력은 기준 미달로 미적용.
- 실제 렌더 후 디코딩 60프레임/3초 확인. 별도 통합 검사에서는 선택된 v2 보정과 일반 클립을 합친 140프레임/7초 출력 확인.
- 주 작업자 회귀 검사 9개 중 데이터/UI 검사 4개와 기존 내부 모션 통합 검사 3개 통과. GUI 실제 작업/취소 검사 2개는 위 QProcess 시작 제약으로 실패했으며 통과로 처리하지 않았다. Windows 심볼릭 링크 권한이 필요한 기존 기반 검사 1개도 환경 제약이다.
- 증거: `outputs/motion-v24-independent/holdout.json`, [독립 검증](M1_M3_INDEPENDENT_VERIFICATION.md), [조정 자료 측정](MOTION_PHASE1_CALIBRATION.md), [선박 비교](MOTION_PHASE1_REAL.md).
- 최종 선박 4개 비교: `outputs/motion-phase1-real/20261012T082646911591Z/`. v2는 네 영상 모두 목표 시간 기본 매핑에서 추가 프레임 변경이 0개다. 두 영상은 후보 없음, 하나는 전체 추적 문맥 신뢰도 부족, 하나는 보호 구간 우선으로 미적용했다. 따라서 이번 결과에서 실제 선박 꿀렁임 감소를 입증했다고 보고하지 않는다.

## 남은 검증과 다음 단계

선박 비교 영상의 사람에 의한 품질 판정, 다른 범주의 실제 영상, 사용자 데스크톱의 작업 실행·취소는 미검증이다. 1차 기술 통과를 범용 시각 품질 보장으로 해석하지 않는다. 2차 M4 보간·M5 공간 안정화는 별도 선택 기능이며 아직 구현하지 않았다. 작업지시서의 순서와 동일한 독립 검증 절차를 따른다.
