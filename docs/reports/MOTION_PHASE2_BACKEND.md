# M4 보간 백엔드 선정과 검증 조건

2026-10-12. 구현 백엔드는 `cpu_flow`, 현재 구현 버전은 `cpu-flow-v1.2`이다. RIFE를 설치하거나 사용한 결과가 아니다.

## 조사 및 선택

RIFE 공식 저장소는 임의의 중간 시각 보간을 지원한다고 안내한다. 저장소 소스의 LICENSE는 MIT이며 저작권·허가 고지를 유지하는 조건이 있다. 공식 requirements에는 PyTorch·torchvision 등이 있고, 평가 안내는 별도 모델 다운로드를 요구한다. 따라서 이 프로젝트에 바로 포함된 기능으로 표시하지 않고 향후 모델 버전·가중치 해시·배포 조건·장비 요구를 함께 확인할 교체 후보로 남겼다. [공식 저장소](https://github.com/hzwer/ECCV2022-RIFE), [소스 라이선스](https://github.com/hzwer/ECCV2022-RIFE/blob/main/LICENSE), [실행 의존성](https://github.com/hzwer/ECCV2022-RIFE/blob/main/requirements.txt)

이번 구현은 이미 설치된 OpenCV의 양방향 Farneback 광학 흐름과 역방향 좌표 매핑을 사용한다. OpenCV 공식 문서는 Farneback을 조밀한 광학 흐름 계산 함수로 설명한다. 선택 이유는 CPU에서 추가 모델 없이 작동하고, 신뢰하지 못하는 영상 쌍을 그대로 반환하는 최소 백엔드를 검증할 수 있기 때문이다. RIFE와 동급 품질이라는 주장은 하지 않는다. [OpenCV 공식 API](https://docs.opencv.org/4.10.0/dc/d6b/group__video__track.html)

## 인터페이스와 처리

`create_backend('cpu_flow').synthesize(left_rgb, right_rgb, alpha)`는 `(RGB uint8 영상, 감사 정보)`를 반환한다. 감사 정보에는 백엔드·구현·OpenCV 버전, 시각 비율, 적용 여부, 이유, 신뢰도와 측정치가 있다. 정확한 끝점은 원본 배열의 복사본으로 반환한다. 실패·불확실성은 alpha가 0.5 이하이면 왼쪽, 그보다 크면 오른쪽 원본을 정확히 반환한다. 입력 쌍 하나만 내용 SHA-256 기준으로 캐시한다.

표시 비율을 유지한 최대 640픽셀 영상에서 양방향 흐름을 측정한다. 전후 흐름 일치와 움직임을 맞춘 밝기 오차를 검사하고, 합격한 경우 시간상 가까운 원본 한 장을 요청 시각으로 이동하여 재구성한다. 반대쪽 원본은 흐름 일치 검증에 사용하고 색을 평균하지 않는다. 단순 혼합과 비교하여 별도 검증한다. 원본 해상도의 출력 좌표를 사용하지만 분석 해상도 이하의 가는 물체·작은 가림·복잡한 변형까지 판정한다는 보장은 없다.

안정화와 함께 사용할 때 `source_frames`와 원본→안정화 좌표의 `source_transforms`를 전달하면, 역방향 흐름 좌표에 역아핀 변환을 합성하여 원본 픽셀에서 한 번만 샘플링한다. 최종 이미지에는 Lanczos4 재구성 필터를 사용하고 흐름 필드 조회에는 선형 보간을 유지한다. 끝점·실패 시에는 전달받은 안정화 프레임을 그대로 반환한다.

독립 검증에서 양쪽 프레임을 정렬한 후 평균해도 서로 다른 원본 샘플링 위상의 디테일이 손실될 수 있음이 확인됐다. v1.2는 위의 가까운 원본 재구성 방식으로 이를 줄인다. 선명화 필터를 추가하거나 품질 기준을 낮추지 않았다. 감사 정보의 `color_reference`가 실제 색을 제공한 왼쪽/오른쪽 원본을 표시하고, `opposite_source_role`은 다른 원본이 흐름 검증에만 쓰였음을 기록한다. alpha=0.5에서 참조가 바뀔 때 완전히 동일한 색·질감이 보장되는 것은 아니다. 교정용 서브픽셀 alpha 연속 검사에서 최대 RGB 오차 4.33/255, 참조 전환 부근 위치 차이 0.158픽셀을 관찰했으며 고정된 오차·위치 기준 안인지 검사한다.

## 독립 검증 전 고정한 구현 판단 기준

- RGB uint8 동일 크기, 최소 가로·세로 16픽셀, alpha는 유한한 0~1.
- 밝기 표준편차 2 미만은 저질감 미적용.
- 평균 절대 차이 25 초과 및 상관 0.2 미만은 컷/큰 변화 미적용.
- 중앙 밝기 차이 4 초과 및 상관 0.9 초과는 조명 변화 미적용.
- 전후 흐름 오차 0.75픽셀 또는 정렬 밝기 오차 20 초과를 불확실 픽셀로 계산.
- 불확실 픽셀 비율 3% 초과, 16픽셀 격자 중 20% 초과, 또는 밝기 오차 95백분위 18 초과이면 쌍 전체 미적용.
- 이동량 99백분위가 짧은 변 길이의 12%를 초과하면 미적용.

자체 단위 검사 8개가 통과했다. 합성 이동의 중간 시각 오차가 원본 선택 및 단순 혼합보다 작고, 선명도 저하로 점수를 얻지 않는지 검사했다. 실제 MP4로 인코딩한 세 프레임을 다시 디코딩하여 양끝에서 만든 중간 영상과 가운데 정답을 비교하는 검사도 포함한다. 서브픽셀 이동·아핀 합성·참조 전환 부근 검사도 포함한다. 이 결과는 사람·선박·불꽃 등 실제 영상 전반의 품질 승인과 다르다. 독립 작업자의 고정된 2차 검증 자료가 최종 기술 판정을 담당한다.
