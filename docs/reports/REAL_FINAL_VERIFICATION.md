# 실제 11초·8초 최종 산출물 독립 검증

판정: **기술 검증 통과 / 주관적 자연스러움은 사용자 확인 대기**.

제품 코드 전체 SHA256을 D_VERIFICATION.md의 고정값과 대조해 변경 없음을 확인했다. 코드·영상은 수정하지 않았고 전체 회귀를 반복하지 않았다.

검증 명령: `.venv/bin/python tests/verification/verify_real_final.py`.

## 결과

| 작업 | 목표·실측 프레임 | 픽셀 대조 |
| --- | --- | --- |
| first-11s | 3+4+4초 = 264프레임, 24fps = 11초 | 전체 264프레임 통과, 최대 평균 오차 1.8054/255 |
| second-8s | 4+4초 = 192프레임, 24fps = 8초 | 전체 192프레임 통과, 최대 평균 오차 1.6599/255 |

- 원본 5개 현재 SHA256을 렌더 보고서·내부 분석 보고서와 대조하여 일치 확인.
- 두 작업의 영상 27개를 ffprobe `-count_frames`로 실제 디코딩. 출력 오디오 없음 확인. 클립별 제작본·진단본 길이도 각각 요청 프레임 예산과 일치.
- 최종 제작본 전체 456프레임의 원본 대응을 스트리밍 디코딩으로 검사. 비교는 320×180으로 축소한 RGB 평균 오차이며 허용 기준 6 미만. 프레임 전체를 메모리에 적재하지 않았다.
- 전체 매핑 단조성, 클립별 첫·마지막 원본 표시 프레임 대응, 처음 1초(0~24 프레임)의 정상 속도 매핑 확인.
- 실제 출력 모든 PTS가 frame/24와 일치하여 공백·겹침 없음. 전체 및 클립별 프레임 예산 충족.
- 경계 3곳의 비교 중앙을 원래 해상도로 디코딩하고 각 화면을 해당 진단본 경계 프레임과 실제 픽셀 대조. 같은 경계 상대 시간 0에 정렬됨 확인.

## 적용된 보정

- 첫 묶음 경계 1: 압축 후 왼쪽 유효 속도 16.77, 오른쪽 6.86을 기준으로 왼쪽 감속 후보(alpha 약 −0.2954) 적용. 오른쪽 시작은 보호 구간 우선으로 유지.
- 첫 묶음 경계 2: 낮은 움직임 신뢰도로 국소 속도 보정 미적용. 이를 정지 장면으로 확정하지 않음.
- 둘째 묶음 경계: 끝 이미지가 비슷해도 흐름 방향 충돌로 국소 속도 보정 미적용.
- 내부 분석은 원본 5개에 의심 구간 1개를 제안. 첫 클립 약 9.1~9.958초 구간이며 기본 선택·명시 선택·제외 목록은 비어 있고 최종 출력에 내부 후보 보정이 적용되지 않음.
- 보호 1초, 전환 0.5초, 최대 배속 12 설정. 공유 끝 프레임은 고정 예산·보호·끝 이미지 제약을 위해 유지되며 중복 제거했다고 표시하지 않음.

## 한계

기술 통과는 꿀렁임 제거 또는 시각적 개선을 보장하지 않는다. 빠르게 압축된 동작과 연결부 자연스러움은 정상 속도로 최종 결과를 보고 사용자가 판단해야 한다. 실제 데스크톱·Windows 배포 검증은 이번 범위 밖이다.
