# SC01 실제 클립 A4 독립 기술 검증

판정: **기술 검증 통과 / 사용자 시각 품질 확인 대기**. 제품 코드 변경 및 전체 회귀 재실행 없이 실제 산출물만 독립 검사했다.

- 입력 순서: SC01 · 01-02 → 01-03 → 01-04. 원본 길이 약 10 / 4 / 10초, 1280×720, 24fps.
- 미래 목표 3 / 4 / 4초는 `input_targets_manifest.json`에 기록만 했으며 적용하지 않았다. B 압축은 미진행.
- `outputs/real-sc01-a4/results`의 영상 10개를 직접 ffprobe `-count_frames`로 검사했다. 기준본·진단본 576프레임/24초, 후보·진단본 575프레임/23.958333초, 각 경계 추출본 38프레임, 비교본 39프레임으로 일치.
- 원본 3개 SHA256이 보고서와 일치. 원본 파일은 수정하지 않았다.
- 기준·후보의 첫/끝 및 경계 주변 총 16개 출력 프레임을 독립 FFmpeg RGB 디코딩하여 매핑된 원본 프레임과 비교했다. 최대 평균 절대 픽셀 오차 2.7475/255로 재인코딩 허용 범위 5 이내.
- 전체 JSON 매핑 단조성, 각 클립 끝 프레임 포함, 클립 2의 공유 첫 프레임만 제거하고 앞 클립 마지막 대표 프레임 유지 확인.
- 경계별 비교 영상의 시작·중앙·끝 총 6개 프레임에서 양쪽 화면을 원래 진단 영상의 경계 상대 위치와 실제 픽셀로 대조하여 시계 일치 확인. 한 번에 필요한 프레임만 디코딩했다.

## 경계별 실제 처리

| 경계 | 실제 적용과 해석 |
| --- | --- |
| 01-02 → 01-03 | 국소 속도 후보 적용, 다음 클립 원본 프레임 0 한 장 제거. 클립 1 선택 프레임 7곳 변경. 클립 2는 제거에 따른 인덱스 이동 외 추가 선택 변경 없음. `positional_schedule_changes=96`을 96개 변속 변경으로 해석하지 않는다. |
| 01-03 → 01-04 | 해당 경계 국소 속도·중복 제거 미적용. 앞쪽 움직임 신뢰도 0.309가 임계값 0.35 미만. 양쪽 freeze_candidate=false이므로 정지 장면이라고 단정하지 않는다. |

자연스러움 개선을 기술 검사로 승인하지 않았다. 실제 정상 속도 비교 영상에 대한 사용자 확인이 있어야 A4 품질 게이트를 통과한다.
