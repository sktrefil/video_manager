M0의 `real_ship_regions.json`에서 서로 다른 앞쪽 4개 원본을 선택했다. 이 목록은 기존 검출기의 의심 구간이며 정답 라벨이 아니다. 원본 SHA-256을 M0 기록과 대조하고 원본 파일을 변경하지 않았다. 목표 시간은 `jobs/spanish_armada_18_clips.json`에서 파일명의 하이픈/밑줄을 정규화하여 찾았다. 보호 구간 1초, 최대 배속 12, 램프 0.5초, 원본 FPS를 사용했다.

## 독립 검증 후 기술 수정 이력

- 저속 물체가 픽셀 단위로 이동할 때 생기는 규칙적인 반복 프레임과 긴 정지 후보를 분리했다. 같은 유형끼리만 영역을 병합하여 정지 후보의 넓은 검토 창이 독립적인 속도 변화 구간을 삼키지 않게 했다.
- 화면 평균 차이가 작아도 작은 물체는 움직일 수 있다. 정지 판단에는 지역 물체 이동과 카메라 이동·회전이 실제로 거의 없는지 함께 요구한다.
- 반복 프레임만으로 의도한 정지인지 오류인지 알 수 없으므로 정지 후보와 실제 정지 프레임 구간에 겹치는 속도 후보는 선택해도 시간 보정을 적용하지 않는다. 원래 정지 구간에 덧붙인 검토용 여백은 별도의 의도 판단 차단 구간으로 쓰지 않는다.
- `motion-components-v2.4`는 품질 비교에 전체 원본 프레임의 움직임 문맥을 요구한다. 기존 점수 계산도 구간 끝에 기록한 속도에 해당 구간 길이를 곱하여 이동 거리를 적분했다. 수정한 부분은 **지역 밖의 누적 이동 거리를 끝값으로 고정하여 가짜 정지 경계를 만들던 입력 범위**다. 이제 전체 원본 범위에서 누적 이동을 구하고 실제 출력 프레임 선택으로 전체 클립의 가속도 분산을 비교한다. 지역 품질도 악화시키지 않아야 한다. 문맥이 없거나 신뢰도가 부족하면 미적용한다.
- 몇 개의 고정 강도만 시험하는 대신 원본 프레임 선택이 바뀌는 강도 경계 사이를 조사한다. 프레임 선택이 동일한 강도 구간의 중간값을 사용하여 부동소수점 경계값에만 의존하는 후보를 피한다. 경계가 4,096개를 넘으면 계산 예산 초과로 미적용한다. 품질 기준 10% 감소·이동 범위 95%·새 반복 증가 2%는 변경하지 않았다.

위 수정은 교정용 합성 회귀 사례로 구현했고 별도 작업자가 고정된 검증 자료를 다시 실행했다. 교정용 `speed_jump`의 3초 출력에서는 전체 추적 거리 기준 가속도 분산이 13.31% 감소하는 후보가 남았고, 2.5초 출력에서는 기준을 만족하지 않아 미적용했다. 실제 원본과 다른 합성 자료에 대한 성공으로 확대 해석하지 않는다. 최종 코드의 실제 비교 재실행은 독립 기술 검증 통과 뒤 완료했으며 결과는 이 문서의 첫 표에 있다.

## 남은 검증

실제 선박에서 정상 동작/오류 정답 라벨, 돛대·밧줄 형태, 잔상, 체감 자연스러움의 사람 검토가 필요하다. 미적용이 많다는 사실은 품질 개선 성공이나 실패를 자동으로 의미하지 않는다. 인물·풍경·제품·빠른 동작 자료가 없어 범용 시각 품질은 검증 대기다. 전역 안정화·프레임 보간·형태 복원 결과는 포함하지 않는다.
