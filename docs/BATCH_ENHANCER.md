# 폴더 영상 보정 프로그램

별도 데스크톱 창에서 선택한 폴더의 영상을 하나씩 처리합니다. 기존 `FrameEffects`, 안정화, 보간, FFmpeg 렌더링 코드를 재사용합니다.

## 설치 및 실행 (Windows PowerShell)

프로젝트 폴더에서 실행합니다. FFmpeg와 ffprobe가 설치되어 있고 PATH에서 실행 가능해야 합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[gui]"
.\.venv\Scripts\video-enhancer.exe
```

또는 `python -m video_manager.ui.batch_enhancer`로 실행할 수 있습니다.

## 사용

1. `폴더 선택`을 눌러 영상이 들어 있는 폴더를 고릅니다. 폴더 바로 안의 MP4, MOV, MKV, AVI, M4V, WEBM 파일을 이름순으로 불러옵니다.
2. 워터마크 제거를 켜 두면 기본 Hailuo AI·Gemini 위치를 주변 픽셀로 메웁니다. 화면 크롭과 확대를 하지 않아 자막 위치와 원본 해상도를 유지합니다.
3. 영상 하나를 선택하고 `선택 파일 영역 미리보기`를 누르면 원본과 인페인팅 결과 예상을 비교할 수 있습니다. 빨간 사각형은 제거할 영역입니다. 앞·중간·끝 장면을 확인하세요. 기본 영역은 예상 위치이며 자동 검출 결과가 아닙니다.
   - 기본 영역과 실제 로고 위치가 다르면 `영역 모두 지우기`를 누르고 로고를 드래그로 둘러싸세요. 여러 로고가 있으면 각각 그립니다. 영역 위에서 우클릭하면 삭제됩니다.
   - `이 파일에 적용`하면 해당 파일의 제거 영역을 저장합니다. 로고가 없는 파일은 영역을 모두 지운 상태로 적용하면 워터마크 제거를 생략합니다.
   - 움직이는 로고는 앞·중간·끝을 포함해 이동하는 전체 영역을 지정하세요. 흔들림 보정이 켜져 있으면 제거 마스크가 흔들림 보정 전에 적용됩니다.
4. 필요한 흔들림 보정과 2배 FPS 프레임 보간을 선택합니다. 보간은 CPU 광학 흐름 방식이라 영상에 따라 처리 시간이 길 수 있습니다.
5. `미완료 파일 처리`를 누릅니다. 각 파일의 상태가 대기, 재처리 필요, 처리 중, 완료 또는 오류로 표시됩니다. 현재 파일이 끝난 다음 중지할 수 있고, 오류 파일 이후의 작업도 계속됩니다.

결과는 입력 폴더의 `video_manager_output`에 `{원본이름}_enhanced_{원본확장자}.mp4`로 저장됩니다. 원본 파일은 변경하지 않습니다. 원본 오디오는 유지되며 AAC로 인코딩됩니다.

완료 판단은 결과 옆의 `.mp4.json` 처리 기록을 사용합니다. 원본 파일·설정·처리 버전·결과 파일이 모두 일치할 때만 건너뜁니다. 이전 크롭 결과는 새 인페인팅 처리 버전과 달라 `재처리 필요`가 되며, 새 처리가 성공한 뒤 결과 파일을 교체합니다. 파일별 영역 설정은 `.mp4.regions.json`에 저장되어 재실행 후에도 유지됩니다.

인페인팅은 주변 픽셀을 참고해 로고가 있던 자리를 채웁니다. 복잡한 무늬나 자막과 겹치는 로고는 흔적이 남거나 자막 일부가 바뀔 수 있으므로, 미리보기에서 영역을 좁게 지정해 확인하세요.
