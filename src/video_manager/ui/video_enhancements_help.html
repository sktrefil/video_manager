본문으로 건너뛰기
Video Manager · 사용 안내

프레임 보간 · 카메라 안정화 · 표시 제거

Video enhancements 탭의 선택 기능을 언제 켜고 어떻게 조절할지 설명합니다. 처음에는 모두 꺼져 있습니다.

이 페이지에서 시작 순서 TTS · 자막 파일 프레임 보간 카메라 안정화 고정 표시 제거 수치 설정 상황별 시작값 결과 확인

시작 순서

  1. 1 · 작업 확인JSON을 불러오고 Clips & timing의 Target, Protect, Enabled를 확인합니다.
  2. 2 · 기능 선택Video enhancements에서 필요한 체크박스만 켭니다. 안정화를 켰다면 아래 수치를 조절합니다.
  3. 3 · 실행과 검토Save JSON으로 설정을 저장한 뒤 Run job을 누릅니다. 결과 영상과 Review & results를 확인합니다.

이 기능은 Run job에서 적용됩니다. Inspect motion 버튼은 기존의 시간 보정 후보를 분석합니다.

중요 · Clips & timing의 Enabled: 끄면 클립은 영상에 이어 붙지만 해당 클립의 인핸스먼츠와 앞뒤 경계의 속도 보정이 함께 비활성화됩니다. 목표 시간이 원본과 크게 다르면 실행 자체가 거절될 수 있습니다. 클립 연결의 꿀렁임을 줄이려면 연결 양쪽 클립의 Enabled를 켜 두세요.

Audio: 기본값은 원본 오디오를 유지합니다. 영상 길이 변경에 따라 원본 오디오의 속도와 음높이가 바뀔 수 있습니다. Mute source audio는 원본 음향만 끄며, 등록한 TTS는 계속 포함됩니다.

Narration / TTS · 파일 등록

Narration / TTS 탭에서 각 항목의 Select 버튼으로 알맞은 파일을 고릅니다. 경로는 작업 JSON에 저장되며, JSON을 다시 불러오면 등록한 파일이 복원됩니다. 아래 예시는 Spanish Armada 프로젝트의 파일명입니다.

  • TTS audio: 실제 음성 원본 스페인TTS.mp3 (또는 MP3/WAV 파일)
  • Final video subtitles: 최종 120초 영상의 자막 시각 Spanish_Armada_Subtitles_120s_Resolve.srt
  • Subtitle to 30-shot mapping: 컷별 자막 대응표 TTS_Subtitle_30Shot_Mapping.csv. 예를 들어 01-01 샷(0–4초)은 자막 1, 2와 겹칩니다.

필요한 파일은 위 세 개뿐입니다. 별도의 추정 타이밍 SRT와 상세 타이밍 CSV는 업로드하지 않아도 됩니다.

검사: 세 파일 등록 후 자동으로, 또는 TTS · SRT · CSV 검사 버튼으로 확인합니다. CSV의 샷 순서·길이·자막 번호가 클립 Target과 SRT에 맞아야 합니다. 일부 파일만 등록했거나 시간이 맞지 않으면 Run job을 시작할 수 없습니다.

자막 모양과 샘플: Narration / TTS 탭에서 설치된 폰트를 고르거나 TTF·OTF·TTC 파일을 추가할 수 있습니다. 글자 크기와 색, 굵기, 검은 외곽선, 좌·중·우 정렬, 여백, 배경 색과 투명도를 설정하세요. 세로 위치는 슬라이더로 위에서 아래까지 세밀하게 조절합니다. 추천 프리셋은 선택 즉시 적용됩니다. 기본 추천은 굵은 흰 글자와 검은 외곽선입니다. 밝거나 복잡한 장면에서는 검정 배경을 켜고 투명도를 55~70%로 설정하면 글자가 안정적으로 읽힙니다. 왼쪽 아래 차콜 상자는 다큐 내레이션에 어울립니다. SRT를 선택하면 큰 미리보기 프레임이 설정 변경에 따라 자동 갱신됩니다. 자막 샘플 만들기를 누르면 현재 샷에서 최대 5초 동안 자막과 TTS를 확인할 수 있습니다. 설정은 작업 JSON에 저장됩니다. 샘플은 해당 시각의 원본 클립 일부를 사용하므로 영상 속도 보정·안정화 결과는 반영되지 않습니다.

Run job 결과: TTS 전체 길이를 영상 길이에 맞추면서 음높이를 유지합니다. 원본 음향은 35%로 낮춰 TTS와 섞고, 설정한 자막 모양을 SRT 시각에 맞춰 화면에 넣습니다. 최종 corrected.mp4와 개별 클립에 적용되며 narration.srt도 결과 폴더에 보관합니다.

동기화 범위: 전체 음성 길이를 맞추는 방식입니다. 음성을 인식하여 각 문장·단어를 재배치하지는 않습니다. 추정 자막은 실제 발화와 다를 수 있으므로 최종 영상을 소리와 함께 확인하세요.

Frame interpolation 기본: 끔

언제 켜나요? 목표 시간에 맞추면서 같은 원본 프레임이 반복되어 움직임이 계단식으로 보일 때 사용합니다.

어떤 효과인가요? 요청된 시각이 원본 두 프레임 사이에 있으면 움직임을 추정해 중간 영상을 만듭니다. 출력 목표 시간과 프레임 수는 늘리지 않습니다.

설정: Frame interpolation을 체크합니다. 이 탭에는 보간 강도 수치가 없습니다. 현재 CPU 방식이 사용되어 처리 시간이 길어질 수 있습니다.

적용 보류: 컷, 가림, 상반된 움직임, 밝기 변화, 낮은 추적 신뢰도에서는 가까운 원본 프레임을 선택합니다. 안정화도 켰다면 그 프레임에는 안정화만 적용될 수 있습니다.

보간이 켜져 있어도 모든 프레임을 생성하지는 않습니다. 결과의 interpolated 수가 0이면 해당 클립에 실제 보간이 적용되지 않은 것입니다.

Camera stabilization 기본: 끔

언제 켜나요? 카메라 전체가 작게 흔들려 수평선이나 배경이 불안정할 때 시도합니다.

어떤 효과인가요? 화면 전체의 작은 이동·회전을 추정해 카메라 경로를 부드럽게 합니다. 의도된 일정한 팬은 유지하려고 하며 화면 가장자리를 일부 잘라야 할 수 있습니다.

설정: Camera stabilization을 체크한 뒤 아래의 강도·평활 시간·최대 크롭을 조절합니다. 먼저 기본값 0.7 / 0.4초 / 5%로 비교해 보세요.

적용 보류: 줌, 장면 전환, 카메라 움직임을 신뢰할 수 없는 경우, 또는 필요한 크롭이 한도를 넘는 경우에는 적용하지 않을 수 있습니다. 한 클립에서 안정화가 전체적으로 보류될 수 있습니다.

선박 원본 4개를 시험했을 때 안정화는 모두 보류됐습니다. 체크했다고 해서 해당 영상의 흔들림이 제거됐다고 해석하면 안 됩니다.

워터마크 제거 기본: 로고 회피 크롭

기본 동작: 새 작업은 Video Enhancer와 같은 Gemini + Hailuo 로고 회피 크롭을 사용합니다. 원본 픽셀을 새로 만들지 않아 인페인팅 흔적을 피하는 대신 화면 가장자리가 잘리고 확대됩니다.

영역 미리보기: 클립을 선택하고 Preview / set crop regions를 눌러 앞·중간·끝 장면의 기본 영역을 확인하세요. 실제 로고와 다르면 드래그해 조정하고, 영역을 적용하면 같은 영역이 모든 클립에 사용됩니다. 안정화가 켜져 있으면 렌더링 시 움직임 범위를 고려해 크롭을 계산합니다.

대체 방식: 드롭다운에서 Gemini, Hailuo 또는 custom fixed mask를 선택하면 주변 픽셀로 로고 자리를 채웁니다. 이 모드에서는 Center X/Y와 Mask width/height를 조절할 수 있지만 복잡한 무늬에는 복원 흔적이 남을 수 있습니다.

수치 설정 이해하기

화면 항목범위 · 기본값조절하면 생기는 일
Stabilization strength0~1 · 0.7보정 이동·회전의 크기입니다. 0이면 보정하지 않습니다. 높이면 흔들림을 더 줄일 수 있지만 크롭 요구와 화면 변형 가능성도 커집니다. 크롭 한도 때문에 실제 적용 강도는 자동으로 낮아질 수 있습니다.
Smoothing seconds0.05~2초 · 0.4초카메라 경로를 평활화하는 시간 범위입니다. 길수록 빠른 흔들림을 더 넓은 시간에 걸쳐 억제하려고 합니다. 의도된 움직임까지 둔하게 느껴지면 줄여 비교하세요.
Maximum crop (total width / height)0~15% · 5%안정화를 위해 허용하는 가로·세로 전체의 최대 크롭 비율입니다. 5%는 각 가장자리에서 정확히 2.5%씩 자른다는 뜻이 아닙니다. 낮추면 화면 가장자리를 더 보존하지만 보정이 보류될 수 있습니다.

상황별 시작값

  • 클립 간 연결이 꿀렁이는 경우: 연결 양쪽 클립의 Clips & timing → Enabled를 켜고, Boundaries에서 해당 연결의 Enabled와 Local speed를 켭니다. Strength가 0보다 큰지 확인하세요. 실제 경계 속도 보정은 분석 결과와 Protect 제약에 따라 보류될 수 있으므로 결과 보고서의 적용 여부를 확인합니다.
  • 반복 프레임이 눈에 띄는 경우: 보간만 켜서 비교합니다. 컷·가림이 많으면 보간된 프레임 수를 확인합니다.
  • 작은 카메라 흔들림: 안정화만 켜고 0.7 / 0.4초 / 5%로 시작합니다. 결과의 크롭과 미적용 사유를 확인합니다.
  • 두 문제가 함께 있는 경우: 두 기능을 켜고 각각 켰을 때의 영상과 비교합니다. 처리 순서는 안정화 다음 보간입니다.
  • 화면 가장자리가 중요한 경우: 최대 크롭을 낮춰 비교합니다. 한도가 너무 작으면 안정화가 적용되지 않을 수 있습니다.
  • 우측 하단 별 또는 하단 Hailuo 표시: 기본 로고 회피 크롭을 사용하고 Preview / set crop regions에서 실제 영역을 확인합니다. 화면 가장자리 손실을 피하려면 인페인팅 모드를 비교할 수 있습니다.

결과에서 확인할 것

  • Review & results: 클립별 보간·안정화 적용 프레임 수와 대표적인 보류 사유를 확인합니다.
  • 최종 영상: Review & results에서 Final video를 선택하면 소리 없는 화면 미리보기를 볼 수 있습니다. Play final video in system player를 누르면 기본 영상 플레이어로 corrected.mp4가 열리고, 결과에 오디오가 있으면 함께 재생됩니다. 움직임, 이음새, 표시 제거 영역을 확인하세요. 자세한 근거는 report.json에 기록됩니다.
  • 보호 구간: 시간 보정·보간·안정화는 첫·마지막 프레임과 Protect로 지정한 초반 구간의 원본 픽셀을 보존합니다. 표시 제거를 켜면 해당 마스크 영역은 모든 프레임에서 바뀝니다.
  • 처리 비용: 영상 보정 기능은 CPU 시간이 추가됩니다. 기능을 켠 최종 영상은 선명도 보존을 위해 큰 파일이 될 수 있습니다. 진단용 미리보기의 화질은 최종 영상과 다를 수 있습니다.

판정 기준: 체크박스가 켜진 상태와 실제 적용은 다릅니다. 출력에서 효과가 적용된 프레임 수와 보류 사유를 먼저 확인하고, 영상 전체를 눈으로 검토하세요.

Video Manager · 이 문서는 프로그램과 함께 로컬에 저장되며 인터넷 연결 없이 열립니다.
